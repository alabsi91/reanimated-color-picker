# ColorInput With Bottom Sheet

A [`ColorInput`](~/components/inputs/color-input/) that opens the color picker in a sheet from
[`@swmansion/react-native-bottom-sheet`](https://docs.swmansion.com/react-native-bottom-sheet/docs/). Type a hex value, or press
the swatch to open the sheet. On a wide screen, `maxWidth` keeps the sheet narrow.
